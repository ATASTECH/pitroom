# Pitroom

Pitroom is installed: you can hand bounded work (research, fixes in an isolated copy, tests, reviews) to cheaper worker agents and get back a verified answer, the exact diff and a receipt. You decide, verify and answer.

Start with the `using-pitroom` skill (a menu of the `pitroom-*` skills and when each pays off). The CLI is `pitroom` (`npm i -g pitroom`; `pitroom doctor` checks the setup). Use it when it helps; for a small task you can do yourself, skip it.
